This is my personal portfolio website, built to showcase my professional background, projects, and technical skills as a Software Engineer. The website highlights my journey from software development to teaching and ongoing learning in modern web technologies.


FEATURES :

Modern Responsive Design — Clean, dark-themed interface optimized for all devices.

Smooth Navigation — Interactive sections with smooth scrolling for better user experience.

Professional Overview — Includes detailed career timeline, skills, and a contact form.

Downloadable Resume — Built-in option to generate and download resume directly.

Contact Form — Functional form that opens prefilled mail for easy communication.

Social Links — Quick access to my GitHub and LinkedIn profiles.


TECHNOLOGIES USED :

Frontend: HTML5, CSS3, JavaScript

Design: Responsive grid layout with custom styles and gradients

Hosting: GitHub Pages


SECTIONS :

Home — Introduction and quick summary.

Experience — My professional journey and key roles.

Projects — Selected works including notification systems and web apps.

Skills — Tech stack across programming and web technologies.

Contact — Direct way to reach out for collaborations or opportunities.
